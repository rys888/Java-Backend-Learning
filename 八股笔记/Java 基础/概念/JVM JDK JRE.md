JVM 是 java 虚拟机，是 java 程序运行的环境，负责将 java 字节码（.class）解释或编译成机器码，并执行程序。JVM 提供了内存管理、垃圾回收、安全性等功能

JDK 是 java 开发工具包，是开发 java 程序所需要的工具集合。包含 JVM、编译器、调试器等开发工具

JRE 是 java 运行时的环境，时 java 程序运行所需要的最小环境。包含 JVM 和一组 java 类库（`String`、`Object`、集合、IO 这些基础类库），用于支持 java 程序执行
