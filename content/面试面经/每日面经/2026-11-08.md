## Java 基础与集合

### 01 字符串常量池与intern的作用

**Q：** 介绍一下字符串常量池 [来源 01](https://www.nowcoder.com/feed/main/detail/792c51bfca37403bb87c2504fd6df982)

**A：** 字符串常量池是 JVM 为了减少重复字符串对象创建、节省内存而设计的一种机制。
当我们使用字符串字面量创建字符串时，JVM 会复用常量池中已有的相同内容的字符串对象。
如果使用 `new String()`，则会显式创建新的 String 对象，所以即使内容相同，引用也可能不同。
字符串常量池在 JDK 6 及以前位于永久代，从 JDK 7 开始移到了 Java 堆中。
此外，字符串常量拼接可能在编译期被优化，而普通变量参与的字符串拼接通常在运行时创建新对象。
String 还提供了 `intern()` 方法，用于获取常量池中的规范化字符串引用。


### 02 List、Set与Map的区别

**Q：** 说一下了解哪些 Java 集合 [来源 01](https://www.nowcoder.com/feed/main/detail/792c51bfca37403bb87c2504fd6df982)

**A：** List表示有序序列，通常允许重复元素，可按下标访问；Set主要表达元素唯一性；Map保存键值映射，键唯一而值可以重复，Map本身不继承Collection。具体顺序和空值规则取决于实现：HashSet不保证迭代顺序，TreeSet按排序规则组织元素。HashMap或HashSet中的自定义键要正确实现equals与hashCode，并避免修改参与判等的字段。选择时先看是否需要位置、去重或按键查询，再考虑并发和性能。

### 03 HashMap 的存储与查找原理

**Q：** 介绍一下 HashMap 底层原理，扩容机制 [来源 01](https://www.nowcoder.com/feed/main/detail/792c51bfca37403bb87c2504fd6df982)

**A：** HashMap 根据键的哈希值定位桶，再通过 equals 区分发生冲突的键。JDK 8 中桶采用链表或红黑树，链较长且数组容量足够时才树化，容量不足时优先扩容；元素数量超过容量与负载因子的乘积也会触发扩容。哈希分布均匀时查询平均接近 O(1)，但不能保证所有场景都为常数时间。它允许 null 键和值，不保证遍历顺序，也不适合并发修改。

### 04 HashMap如何扩容

**Q：** 介绍一下 HashMap 底层原理，扩容机制 [来源 01](https://www.nowcoder.com/feed/main/detail/792c51bfca37403bb87c2504fd6df982)

**A：** 以JDK 8为例，HashMap通常在元素数量超过容量乘负载因子的阈值时扩容，新桶数组一般扩大为原来的两倍。迁移节点时利用容量为二的幂这一特点，检查哈希值与旧容量对应的位，节点留在原位置或移动到原下标加旧容量的位置，不需要重新调用键的hashCode。扩容有分配和迁移成本，可按预计规模设置初始容量；这些规则并不使HashMap具备并发安全性。

### 05 接口与抽象类有什么区别

**Q：** 接口和抽象类的区别 [来源 02](https://www.nowcoder.com/discuss/938437442237890560)

**A：** AI参考答案：接口主要定义能力契约，一个类可以实现多个接口；抽象类适合表达同一类型体系中的共享状态和部分实现，一个类只能直接继承一个类。抽象类可以有实例字段、构造器和不同可见性的方法；接口字段是常量，不能保存每个对象的实例状态。Java 8接口可有default和static方法，Java 9起还可有private方法。选择时优先根据类型关系与职责决定，不要仅为了代码复用建立不合理继承。

### 06 final修饰变量、方法与类的含义

**Q：** final关键字作用在变量、方法、类上分别是什么效果，引用类型要注意什么 [来源 02](https://www.nowcoder.com/discuss/938437442237890560)

**A：** final修饰变量表示只能赋值一次；引用变量不能再指向其他对象，但对象内部状态仍可能变化，所以不等于不可变或线程安全。修饰方法表示不能被子类重写，修饰类表示不能被继承。成员final字段需在声明、初始化块或构造过程中完成赋值；局部变量需在使用前赋值。并发中final字段有专门的初始化可见性语义，但前提包括构造期间不让this逸出，仍不能代替对可变共享状态的同步。

**Q：** Java 中如何排查内存溢出的情况 [来源 01](https://www.nowcoder.com/feed/main/detail/792c51bfca37403bb87c2504fd6df982)

### 08 自定义线程池与七个核心参数

**Q：** 如何设置线程池参数 [来源 01](https://www.nowcoder.com/feed/main/detail/792c51bfca37403bb87c2504fd6df982)

**A：** ThreadPoolExecutor常见七个参数是corePoolSize、maximumPoolSize、keepAliveTime、时间单位、任务队列、ThreadFactory和拒绝处理器。配置需结合CPU或IO特征、下游容量、允许排队时间和资源限制，不能只套公式。优先使用有界队列，并给线程命名、监控活跃数和拒绝次数；长队列可能延迟扩容，最大线程数也不能超出系统可承受范围。

### 09 线程池提交任务流程与拒绝策略

**Q：** 线程池中常用的拒绝策略 [来源 01](https://www.nowcoder.com/feed/main/detail/792c51bfca37403bb87c2504fd6df982)

**A：** 提交任务时，若工作线程少于核心数就尝试创建核心线程；否则尝试入队。入队成功后还会复查运行状态与工作线程情况；入队失败则尝试创建非核心线程，达到上限或无法接收时执行拒绝策略。Java内置Abort、CallerRuns、Discard和DiscardOldest。选择要结合业务是否允许丢任务，不能默认静默丢弃；关闭中的线程池也可能拒绝任务。

### 11 MyBatis二级缓存的范围与一致性

### 12 Spring AOP的作用与实现

**Q：** 说一下对 SpringAOP 的理解 [来源 01](https://www.nowcoder.com/feed/main/detail/792c51bfca37403bb87c2504fd6df982)

### 13 Spring事务的传播行为有哪些

**Q：** @Transactional事务的传播属性有哪些 [来源 02](https://www.nowcoder.com/discuss/938437442237890560)

这部分没有背过
**A：** AI参考答案：传播行为描述调用事务方法时如何处理已有事务。REQUIRED默认加入已有事务，没有则新建；REQUIRES_NEW挂起外层并独立新建；NESTED通常借助保存点局部回滚，需事务管理器支持。SUPPORTS有则加入、无则非事务；MANDATORY要求已有事务；NOT_SUPPORTED挂起事务；NEVER禁止已有事务。加入同一物理事务的内层标记回滚会影响外层，独立新事务还要考虑连接池容量；代理模式下同类自调用通常不会触发这些设置。

### 17 MySQL常见存储引擎及区别

**Q：** InnoDB和MyISAM存储引擎区别 [来源 02](https://www.nowcoder.com/discuss/938437442237890560)

**A：** AI参考答案：常见引擎有**InnoDB、MyISAM、MEMORY**等。MySQL 8.0默认InnoDB，支持事务、崩溃恢复、外键和行级锁，适合常见业务表。MyISAM不支持事务，主要使用表级锁；MEMORY将数据保存在内存中，重启后数据会丢失，不能代替持久业务存储。选择应看事务、一致性、恢复能力和访问模式，不能单凭读写速度作结论。
