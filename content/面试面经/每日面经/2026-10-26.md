### 02 方法重载与重写的区别

**Q：** Java 中，方法重载（Overload）和方法重写（Override）有什么区别？ [来源 03](https://www.nowcoder.com/discuss/932329388496945152)

**A：** 重载是在同一类或继承体系中使用相同方法名、不同参数列表，编译器根据声明类型和参数选择调用目标，不能只改变返回类型来重载。重写是子类对继承的实例方法提供兼容实现，调用时再按对象实际类型动态分派；返回类型需兼容，不能收紧访问权限或任意扩大受检异常范围。静态方法是隐藏而非实例方法重写，私有方法也不按普通重写规则参与动态分派。

## Java 并发与 JVM

### 03 G1如何划分堆内存

**Q：** G1 的内存分块情况？相对之前的新生代/老年代有什么改变？ [来源 01](https://www.nowcoder.com/feed/main/detail/45c6d1c751e84ec2b3974ec2e4af9e06)

**A：** G1把堆划分为多个大小相同的Region，按需要把部分Region作为Eden、Survivor或老年代使用，因此仍然是分代收集，只是不再要求各代占据固定连续的大块区域。大对象还可能占用连续的专用Region。回收时通过复制整理，把存活对象迁移到其他Region，并按垃圾收益和暂停目标选择回收集合。暂停目标是优化目标而非绝对时限，不能认为启用G1就不再出现停顿或Full GC。

**Q：** 线程池的运行逻辑是什么？ [来源 01](https://www.nowcoder.com/feed/main/detail/45c6d1c751e84ec2b3974ec2e4af9e06)

**Q：** 拒绝策略有哪几种？ [来源 01](https://www.nowcoder.com/feed/main/detail/45c6d1c751e84ec2b3974ec2e4af9e06)

**A：** 提交任务时，若工作线程少于核心数就尝试创建核心线程；否则尝试入队。入队成功后还会复查运行状态与工作线程情况；入队失败则尝试创建非核心线程，达到上限或无法接收时执行拒绝策略。Java内置Abort、CallerRuns、Discard和DiscardOldest。选择要结合业务是否允许丢任务，不能默认静默丢弃；关闭中的线程池也可能拒绝任务。

### 06 Java创建和执行线程任务的方式

**Q：** Java 中，如何创建一个新的线程？ [来源 03](https://www.nowcoder.com/discuss/932329388496945152)

**A：** 可继承Thread重写run，或把Runnable交给Thread后调用start；需要返回值时可用Callable配合FutureTask或提交给ExecutorService。Runnable、Callable描述任务，本身不是操作系统线程；调用run只是当前线程普通方法调用，start才请求启动新线程。实际工程常使用受控线程池复用线程，并处理任务异常、超时和关闭流程，不能无界地为每个请求新建线程。

### 07 JWT的用途、结构与校验

**Q：** JWT 是做什么的？ [来源 01](https://www.nowcoder.com/feed/main/detail/45c6d1c751e84ec2b3974ec2e4af9e06)

**Q：** JWT 的 Token 包含多少段？ [来源 01](https://www.nowcoder.com/feed/main/detail/45c6d1c751e84ec2b3974ec2e4af9e06)

**A：** JWT可用于携带签名的身份声明。常见的签名JWT采用紧凑JWS表示，由Header、Payload和Signature三段组成；前两段只是编码，默认并不保密，所以不应放密码等敏感数据。服务端不能只解码就信任内容，还应校验签名、允许的算法、有效期及业务要求的签发者和受众。客户端按约定携带令牌，授权判断仍由服务端完成；若需要立即撤销，可结合服务端会话或名单机制。

### 08 Spring AOP的作用与实现

**Q：** Spring 的 AOP 依赖什么实现？ [来源 01](https://www.nowcoder.com/feed/main/detail/45c6d1c751e84ec2b3974ec2e4af9e06)

**A：** AOP把事务、日志或权限等横切逻辑从业务代码中分离，通过切点选择连接点并织入通知。Spring AOP通常基于JDK动态代理或CGLIB代理，在代理调用处增强方法，因此对象是否由容器管理、调用是否经过代理会影响增强生效。它不是修改所有类的任意代码位置，也不等同于完整的AspectJ编织；项目中的声明式事务可作为有代码依据的典型应用。

### 09 JDK动态代理与CGLIB的区别

**Q：** 动态代理有哪几种？ [来源 01](https://www.nowcoder.com/feed/main/detail/45c6d1c751e84ec2b3974ec2e4af9e06)

**Q：** JDK 动态代理和 CGLIB 有什么区别？ [来源 01](https://www.nowcoder.com/feed/main/detail/45c6d1c751e84ec2b3974ec2e4af9e06)

**A：** JDK动态代理通常基于接口生成代理对象，通过InvocationHandler转发调用；CGLIB通过生成目标类的子类实现增强，因此不能靠子类重写增强final方法，也不能继承final类。Spring AOP可根据配置和目标类型选择实现，不能笼统说始终使用其中一种。无论哪种代理，普通同类内部直接调用都可能绕过代理增强；判断事务或切面是否生效，要看实际调用是否经过代理对象。

### 10 Spring事务不生效与不回滚的场景

**Q：** @Transactional 什么情况下会失效？ [来源 01](https://www.nowcoder.com/feed/main/detail/45c6d1c751e84ec2b3974ec2e4af9e06)

**A：** 先区分没有进入事务与进入后没有回滚。代理模式下，同类内部直接调用、对象不是Spring管理的Bean等会绕开事务代理；方法可见性和代理类型也要结合版本判断。已进入事务时，异常被业务捕获不再抛出，或受检异常未匹配回滚规则，可能不会按预期回滚。新线程不会自动继承当前线程事务。排查要看调用链、管理器与实际SQL，不能只看方法上有注解。

### 11 数据库查询如何调优

**Q：** 给你一个慢 SQL，怎么分析和解决？ [来源 01](https://www.nowcoder.com/feed/main/detail/45c6d1c751e84ec2b3974ec2e4af9e06)

### 12 EXPLAIN执行计划怎么看

**Q：** explain 能得到什么信息？ [来源 01](https://www.nowcoder.com/feed/main/detail/45c6d1c751e84ec2b3974ec2e4af9e06)

**A：** EXPLAIN主要观察优化器选择的访问路径。结合type判断访问方式，possible_keys和key区分候选与实际索引，key_len辅助分析索引使用情况，rows与filtered查看估计扫描和过滤规模，Extra了解覆盖索引、额外排序等信息。字段要联动分析，不能仅凭用了索引就断言高效；估计值也不是实际耗时。MySQL 8.0.18起提供EXPLAIN ANALYZE，会实际执行支持的查询并给出运行信息，生产使用前需评估开销。

### 13 INNER JOIN与LEFT JOIN的结果差异

**Q：** MySQL 中，INNER JOIN 和 LEFT JOIN 在查询结果集上有什么区别？ [来源 03](https://www.nowcoder.com/discuss/932329388496945152)

**A：** INNER JOIN只保留满足连接条件的匹配行；LEFT JOIN除匹配行外，还保留左表未匹配的行，并把对应右表列补为NULL。一对多关系仍可能产生多行结果，不能理解为左连接永远与左表行数相同。右表筛选条件放在ON中或WHERE中可能改变结果：WHERE若要求右表列等于某值，通常会排除那些补NULL的未匹配行。应先明确是否需要保留左表记录，再决定条件位置。

### 14 Lua在Redis Cluster中的约束

**Q：** 集群模式下写 Lua 要注意什么？ [来源 01](https://www.nowcoder.com/feed/main/detail/45c6d1c751e84ec2b3974ec2e4af9e06)

**A：** Lua可把多个Redis操作放在一次脚本执行中，减少往返并避免其他命令穿插，但原子执行不等于出错时自动回滚已做修改。脚本应显式传入所访问的键，避免长时间阻塞服务；在Cluster中，相关键需满足同槽要求，可按业务设计hash tag。脚本不能把数据库和消息队列也纳入原子范围，更不能只因单机测试通过就宣称已经适配集群。

**项目结合（AI）**：研约通的预约Lua同时访问名额键与用户集合键，校验时间、余量及重复预约后执行DECR、SADD和EXPIRE。ReservationQuotaExecutor传入两个键，现有拼接未使用Cluster hash tag；因此不能声称这段代码已适配跨槽。若部署Cluster，应先设计同批次同槽键并验证，这属于待实施建议。

代码依据：[ReservationServiceImpl.submit](https://github.com/rys888/yanyuetong/blob/0170f0c1f0f94216ba111c1d5e7ea771be4d77ce/src/main/java/com/yanyuetong/service/impl/ReservationServiceImpl.java#L80)。


## A：
在 Redis Cluster 模式下使用 Lua，最重要的是保证脚本操作的所有 Key 位于同一个 Hash Slot，因为 Redis Lua 脚本不能跨节点执行。

如果脚本需要操作多个 Key，可以通过 Hash Tag，也就是在 Key 中使用相同的 `{}` 内容，让这些 Key 分配到同一个槽。

此外，Lua 脚本应该通过 KEYS 显式传入操作的 Key（这样才可以知道是在哪些 hash 槽中），并避免执行耗时过长的逻辑，因为脚本执行期间会阻塞所在节点。

最后需要注意，Lua 可以保证脚本执行期间不被其他命令插入，但不支持执行出错后的自动回滚。

### 15 HTTP、HTTPS与TLS握手

**Q：** HTTP 和 HTTPS 的区别？ [来源 01](https://www.nowcoder.com/feed/main/detail/45c6d1c751e84ec2b3974ec2e4af9e06)

**Q：** TLS 的加解密过程？用什么算法加密、解密？ [来源 01](https://www.nowcoder.com/feed/main/detail/45c6d1c751e84ec2b3974ec2e4af9e06)

**A：** HTTPS通过TLS保护HTTP传输，提供身份认证、机密性和完整性。以常见TLS 1.3证书握手为例，双方协商参数，通常用ECDHE交换密钥材料、派生会话密钥，用RSA-PSS或ECDSA等签名完成身份验证，再用AES-GCM或ChaCha20-Poly1305等对称算法保护应用数据。还需校验证书信任链、域名和有效期；不能说全程公钥加密，也不能把旧版RSA密钥交换当成所有TLS版本通用流程。

### 16 WebSocket与普通HTTP的区别

**Q：** WebSocket 和普通 HTTP 有什么区别？ [来源 01](https://www.nowcoder.com/feed/main/detail/45c6d1c751e84ec2b3974ec2e4af9e06)

**A：** 普通HTTP围绕请求与响应交互，长连接只是允许复用底层连接，不等于服务端能随时主动推送任意消息。WebSocket常见实现通过HTTP/1.1 Upgrade建立连接后，使用自己的帧协议进行双向通信，适合聊天或实时协作；单向通知也可评估SSE。实际使用还要处理鉴权、心跳、断线重连和慢客户端，不能因为有持久连接就省略消息顺序、补发或业务确认机制。

### 17 单点登录如何实现

**Q：** 单点登录怎么做的 [来源 02](https://www.nowcoder.com/feed/main/detail/3375e792921b46a0ae44aefae6fbcba3)

**A：** 单点登录要解决用户在多个业务系统间只认证一次的问题，可使用统一身份提供方和标准协议，例如OpenID Connect授权码流程。业务系统把用户引导到认证中心，认证完成后校验回调状态并交换、校验令牌，再建立自己的登录态；跨域时不能简单共享任意Cookie。还要设计令牌有效期、退出及撤销策略。JWT只是令牌的一种格式，给各系统发JWT不等于已经完成安全的单点登录。
