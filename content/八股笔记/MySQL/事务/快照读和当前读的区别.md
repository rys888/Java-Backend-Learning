
**快照读和当前读最大的区别是：快照读读取符合事务可见性规则的数据版本，而当前读读取当前最新的数据，并通过加锁保证并发操作的正确性。**

### **一、举个例子**

假设数据库中有一条记录：

```text
id = 1
balance = 1000
```

现在有两个事务：

```text
事务 A                         事务 B
  │                              │
  ├── BEGIN                      │
  │                              │
  ├── SELECT balance             │
  │   结果：1000                  │
  │                              │
  │                              ├── UPDATE
  │                              │   balance = 500
  │                              │
  │                              ├── COMMIT
  │                              │
  ├── SELECT balance             │
  │   结果：1000                  │
  │                              │
  ├── SELECT ... FOR UPDATE      │
  │   结果：500                   │
```

假设事务 A 使用 MySQL 默认的 **RR（可重复读）隔离级别**。

为什么两次查询结果不同？

**① 快照读**

```sql
SELECT balance FROM account WHERE id = 1;
```

普通 `SELECT` 属于快照读。

它通过 MVCC 的 Read View 判断数据版本是否可见。

即使事务 B 已经提交修改，事务 A 仍然可以通过 Undo Log 读取旧版本 `1000`。

**② 当前读**

```sql
SELECT balance FROM account WHERE id = 1 FOR UPDATE;
```

`SELECT ... FOR UPDATE` 属于当前读。

它不会使用之前的 Read View 读取旧版本，而是读取当前最新的有效数据，并对相关记录加锁。

由于事务 B 已经提交，因此事务 A 读取到 `500`。

注意：如果事务 B 尚未提交且持有冲突的锁，当前读通常需要等待，而不是直接读取它未提交的数据。

---

### **二、哪些 SQL 属于快照读？哪些属于当前读？**

|**快照读**|**当前读**|
|---|---|
|普通 `SELECT` | `SELECT ... FOR UPDATE` |
|| `SELECT ... FOR SHARE` |
|| `UPDATE` |
|| `DELETE` |

其中，`UPDATE` 和 `DELETE` 虽然不是查询语句，但需要基于当前数据进行判断和修改，因此也属于当前读的范畴。

### **三、两者有什么区别？**

|**对比**|**快照读**|**当前读**|
|---|---|---|
|读取的数据|符合 Read View 的历史或当前版本|当前最新的有效版本|
|实现机制|MVCC|锁机制|
|是否加行锁|通常不加|会对相关记录加锁|
|是否可能读取旧版本|可以|不通过旧快照读取历史版本|
|主要目的|提高读写并发性能|保证并发操作的数据正确性|

### **四、面试怎么回答？⭐⭐⭐⭐⭐**

MySQL 中的快照读和当前读主要区别在于读取的数据版本和实现机制。

**快照读**主要指普通 SELECT，通过 MVCC 的 Read View 和 Undo Log 读取符合可见性规则的数据版本，通常不需要加行锁，因此可以提高读写并发性能。

**当前读**主要包括 SELECT FOR UPDATE、UPDATE 和 DELETE 等操作，它们读取当前最新的有效数据，并通过锁机制保证并发操作的正确性。

例如，在 RR 隔离级别下，即使其他事务已经提交修改，快照读仍然可能读取旧版本，而当前读会读取最新的有效版本。

**一句话记忆：快照读通过 MVCC 读取可见版本，当前读通过加锁读取最新有效数据。**

另外，这里有个非常重要的联系：**InnoDB 在 RR 隔离级别下，快照读主要通过 MVCC 避免幻读，而当前读主要通过间隙锁、临键锁等机制防止特定范围内的幻读。**
