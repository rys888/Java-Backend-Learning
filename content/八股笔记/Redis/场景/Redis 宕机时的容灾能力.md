
1. **持久化**：通过 RDB 快照或 AOF 日志，将数据持久化到磁盘，宕机重启后可恢复数据。
2. **主从复制**：采用主从架构，主节点宕机后，从节点可以提升为主节点（需手动或借助哨兵/集群自动切换）。
3. **哨兵模式**：哨兵节点监控主节点状态，当主节点宕机时，自动进行故障转移，选举新的主节点，并通知客户端更新连接。
4. **Redis Cluster**：集群模式通过分片和复制，部分节点宕机不影响整体服务，只要每个分片有至少一个从节点可用，集群能自动完成故障转移。


RDB：数据快照，每隔一段时间将 Redis 内存中的数据生成一份快照，保存到磁盘。
AOF 就是将 Redis 执行的写命令记录到文件中，重启时通过这些记录恢复数据。

注重哨兵模式和 Redis 集群的区别，Redis Cluster 不需要哨兵进行监控
