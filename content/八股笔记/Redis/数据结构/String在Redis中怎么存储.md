
[[#Q：]]

Redis 的 String 类型主要使用 **SDS（Simple Dynamic String，简单动态字符串）** 存储字符串内容，而不是直接使用 C 语言传统的字符串。

原因是：**SDS 在字符串长度获取、修改效率和二进制安全性方面，比 C 字符串更适合 Redis。**

### **一、C 语言字符串长什么样？**

假设存储 `"Eason"`：

```text
C 字符串

┌───┬───┬───┬───┬───┬────┐
│ E │ a │ s │ o │ n │ \0 │
└───┴───┴───┴───┴───┴────┘
```

C 字符串通过末尾的 `\0` 判断字符串在哪里结束。

例如执行：

```c
strlen("Eason");
```

需要从头遍历字符，直到遇到 `\0`。

因此，**获取字符串长度的时间复杂度为 O(N)**。

### **二、Redis 的 SDS 长什么样？**

Redis 使用 SDS，可以简单理解为：

```text
SDS

┌─────┬───────┬─────────────────────────┐
│ len │ alloc │           buf           │
├─────┼───────┼─────────────────────────┤
│  5  │  10   │ E a s o n _ _ _ _ _ \0  │
└─────┴───────┴─────────────────────────┘
```

其中：

- **len = 5**：当前字符串长度。
- **alloc = 10**：分配给字符串内容的总容量。
- **buf**：真正存储字符串的字符数组。

这里的 `alloc = 10` 只是示例，实际分配容量由 Redis 决定。

### **三、为什么 Redis 不直接使用 C 字符串？**

主要有三个原因。

**① 获取字符串长度更快**

C 字符串：

```text
E → a → s → o → n → \0
```

需要遍历才能知道长度。

SDS：

```text
len = 5
```

直接读取即可。

因此：

- C 字符串：O(N)
- SDS：O(1)

**② 减少字符串修改时的内存操作**

假设原本存储：

```text
Eason
```

现在追加：

```text
123
```

变成：

```text
Eason123
```

传统 C 字符串需要程序员自行管理内存空间，确保有足够容量。

而 SDS 会检查剩余空间：

```text
len = 5
alloc = 10

追加 "123"
      ↓
len = 8
alloc = 10
```

因为空间足够，可以直接追加。

如果空间不足，SDS 会自动扩容。

**③ SDS 是二进制安全的**

C 字符串依靠 `\0` 判断结束位置。

假设存储：

```text
abc\0def
```

传统 C 字符串函数通常只能识别前面的 `abc`。

而 SDS 通过 `len` 记录实际长度，因此可以完整保存：

```text
abc\0def

len = 7
```

这意味着 Redis String 不仅能存储普通文本，还能存储图片、序列化数据等二进制内容。

---

### **四、Redis String 一定使用 SDS 吗？**

**不一定。**

Redis String 对象有三种常见编码：

|**编码**|**使用场景**|
|---|---|
|int|可以用整数表示的值|
|embstr|较短的字符串|
|raw|较长的字符串|

其中，`embstr` 和 `raw` 都涉及 SDS，主要区别在于内存分配方式。

例如：

```redis
SET age 20
SET name "Eason"
```

`age` 可能采用 `int` 编码，而 `name` 通常采用 `embstr` 编码。

## Q：

Redis String 主要使用 SDS，也就是简单动态字符串来存储字符串内容。

相比 C 语言传统字符串，SDS 有三个优势。

第一，SDS 通过 len 字段记录字符串长度，获取长度的时间复杂度是 O(1)。

第二，SDS 会记录已分配的空间，并支持动态扩容，减少不必要的内存分配，同时降低缓冲区溢出的风险。

第三，SDS 是二进制安全的，不依赖 `\0` 判断字符串结束，因此可以存储任意二进制数据。

此外，Redis String 对象还可以采用 int、embstr 和 raw 三种编码。


**SDS = 字符数组 + 长度记录 + 容量管理，解决了传统 C 字符串长度获取慢、内存管理不便和二进制不安全的问题。**
