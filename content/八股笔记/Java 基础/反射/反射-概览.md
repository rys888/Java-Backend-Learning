## Q：什么是 Java 反射

Java 反射是指程序在运行时动态获取类的信息，并对类或对象进行操作的机制。

在 Java 中，每个被加载的类都会有对应的 `Class` 对象，它保存了**类的相关元信息**。我们可以通过这个 `Class` 对象获取类的名称、字段、方法、构造器、注解等信息，也可以在运行时动态创建对象、访问字段和调用方法。

例如用 `Class.forName()` 根据类名拿到 `Class` 对象，再用 `getDeclaredConstructor().newInstance()` 创建对象，用 `getDeclaredMethod()` 拿到方法，最后用 `invoke()` 调用。

Spring、MyBatis 等框架大量使用了反射，它让框架能够在运行时根据配置、注解等信息动态创建对象和调用方法。
