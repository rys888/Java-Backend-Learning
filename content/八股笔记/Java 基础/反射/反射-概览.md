## Q：什么是 Java 反射

Java 反射是指程序在运行时动态获取类的信息，并对类或对象进行操作的机制。

可以通过 `Class` 对象获取类的名称、字段、方法、构造器等信息，也可以动态创建对象、调用方法、访问字段。例如用 `Class.forName()` 根据类名拿到 `Class` 对象，再用 `getDeclaredConstructor().newInstance()` 创建对象，用 `getDeclaredMethod()` 拿到方法，最后用 `invoke()` 调用。

Spring、MyBatis 等框架大量使用了反射，它让框架能够在运行时根据配置、注解等信息动态创建对象和调用方法。
