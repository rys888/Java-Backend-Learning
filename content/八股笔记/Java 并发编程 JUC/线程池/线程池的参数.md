## Q：线程池的参数说说

`ThreadPoolExecutor` 主要有七个核心参数。

第一个是 **corePoolSize，核心线程数**，表示线程池正常情况下维持的核心工作线程数量。任务到来时，如果当前工作线程数小于核心线程数，会优先创建 Worker 来执行任务。

第二个是 **maximumPoolSize，最大线程数**，表示线程池允许创建的最大工作线程数量。当核心线程已经满了，并且任务队列也满了，线程池会继续创建线程，直到达到最大线程数。

第三个是 **keepAliveTime，空闲线程存活时间**，默认主要用于超过核心线程数的线程。当这些线程空闲超过这个时间后，会被回收。

第四个是 **unit**，就是 keepAliveTime 对应的时间单位，比如秒、毫秒。

第五个是 **workQueue，工作队列**，它是一个 `BlockingQueue<Runnable>`，当核心线程都在工作时，新提交的任务会优先进入这个队列等待执行，比如可以使用 `ArrayBlockingQueue`。

第六个是 **threadFactory，线程工厂**，用于创建 Worker 对应的线程，可以通过它设置线程名称等属性，方便管理和排查问题。

第七个是 **handler，拒绝策略**。当线程数量已经达到 maximumPoolSize，并且 workQueue 也满了，就会执行拒绝策略。JDK 默认提供 `AbortPolicy`、`CallerRunsPolicy`、`DiscardPolicy` 和 `DiscardOldestPolicy` 四种。

所以整个任务处理流程可以概括成：**核心线程 → 工作队列 → 最大线程 → 拒绝策略。**
