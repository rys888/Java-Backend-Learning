这里有一个特别容易混的点：**方法区存“类和方法的相关信息”，但方法真正执行时，主要是在当前线程的虚拟机栈中创建栈帧来完成的。** 所以并不是“方法在方法区里执行”。

假设有这么个类：

```java
public class UserService {

    public int add(int a, int b) {
        int c = a + b;
        return c;
    }
}
```

可以先有个整体印象：

```text
              JVM
               │
     ┌─────────┴──────────┐
     ↓                    ↓
   方法区               虚拟机栈
（线程共享）            （线程私有）

UserService类信息         Thread A
add方法相关信息              │
相关运行时常量池信息          ↓
                         add()栈帧
                         ├─ a = 10
                         ├─ b = 20
                         ├─ c
                         └─ 操作数栈
```

## 方法执行的完整过程

假设调用 `int result = userService.add(10, 20);`，第一步 JVM 首先要知道：`UserService` 是什么？`add()` 是哪个方法？类加载之后，类的相关元数据、方法信息、运行时常量池等会有对应的运行时表示，方法区里关于 `UserService` 的内容大致就是**类相关信息、字段相关信息、`add(int, int)` 方法相关信息、运行时常量池**这几块。

然后真正开始调用 `add()`，此时当前线程的 **JVM 虚拟机栈**会创建一个新的栈帧：

```text
Thread A 的 JVM Stack

┌────────────────────────┐
│ add() 栈帧              │
│                        │
│ 局部变量表              │
│ a = 10                 │
│ b = 20                 │
│                        │
│ 操作数栈                │
│ ...                    │
└────────────────────────┘
```

接着执行 `int c = a + b;`，JVM 执行相应字节码，过程中会用到**局部变量表 + 操作数栈**，可以非常粗略地理解成：

```text
局部变量表

a = 10
b = 20

       ↓ 加载

操作数栈

┌────┐
│ 20 │
├────┤
│ 10 │
└────┘

       ↓ 加法

┌────┐
│ 30 │
└────┘

       ↓ 保存

局部变量表

a = 10
b = 20
c = 30
```

最后执行 `return c;`，把 30 返回给调用者：**add() 栈帧 → 返回 30 → 栈帧出栈 → 调用者继续执行**。

所以完整流程可以记成：

1. 类加载；
2. 类/方法相关运行时信息可供 JVM 使用（方法区）；
3. 调用 `add()`；
4. 当前线程 JVM Stack 创建 add 栈帧；
5. 参数进入局部变量表；
6. 执行字节码；
7. 操作数栈参与计算；
8. `return` 返回结果；
9. add 栈帧出栈。

### 那方法区到底干了什么？

可以把它和虚拟机栈这样区分：**方法区提供“这个类/方法是什么”的类级运行时信息**，**虚拟机栈保存“这个线程这一次方法调用执行到什么状态”的栈帧**。

比如两个线程同时调用 `add()`，并不会复制两份 `UserService` 的方法信息：

```text
                   方法区（共享）
                        │
                 UserService
                  add方法信息
                    ↙    ↘
                   /      \
          Thread A          Thread B
          JVM Stack         JVM Stack

          add栈帧            add栈帧
          a = 10            a = 100
          b = 20            b = 200
```

**方法相关的类级信息可以共享，但每个线程的这一次方法调用都有自己的栈帧。** 这也解释了为什么**方法区是线程共享的，虚拟机栈是线程私有的**。

## Q：Java 方法是存储在方法区里，然后在方法区里执行的吗？

不是。方法区主要存储类相关的运行时信息，包括类元数据、方法相关信息、运行时常量池等，它是线程共享的。真正发生方法调用时，会在当前线程的 Java 虚拟机栈中创建对应的栈帧，栈帧包含局部变量表、操作数栈、动态链接和方法返回相关信息。方法执行完成后，结果返回给调用者，对应栈帧出栈。

**方法区管“方法是什么”，虚拟机栈管“这次方法怎么执行”。**
