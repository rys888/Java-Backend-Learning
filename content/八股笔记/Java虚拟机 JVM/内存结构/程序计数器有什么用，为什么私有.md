程序计数器（Program Counter Register，PC）你可以把它理解成：

**程序计数器 = 当前线程执行字节码的“书签”，记录线程下一步该从哪里继续执行。**

### **为什么需要程序计数器？**

Java 程序最终会被多个线程交替执行。

假设 Thread A 正在执行：

```java
int a = 10;
int b = 20;
int c = a + b;
System.out.println(c);
```

可以粗略理解成 JVM 在执行一系列字节码：

```text
Thread A

指令1：加载 10
指令2：保存到 a
指令3：加载 20
指令4：保存到 b
指令5：计算 a + b    ← 当前执行位置
指令6：保存到 c
指令7：打印 c
```

此时程序计数器相当于记录：

```text
PC → 当前/下一条需要执行的字节码指令位置
```

它的核心作用就是：

**帮助 JVM 知道线程当前执行到了哪里。**

---

### **为什么它必须是线程私有的？⭐⭐⭐⭐⭐**

因为 Java 是多线程的。

假设现在有两个线程：

```text
Thread A                   Thread B

代码执行到第 20 条          代码执行到第 80 条
      ↑                          ↑
   PC = 20                    PC = 80
```

CPU 不一定让 A 一直执行到底，而可能：

```text
Thread A 执行
    ↓
CPU切换
    ↓
Thread B 执行
    ↓
CPU再切回来
    ↓
Thread A继续
```

那么问题来了：

CPU 切回 Thread A 后，怎么知道 A 刚才执行到哪里了？

Thread A 必须有自己的执行位置记录。

因此：

```text
Thread A
├── JVM Stack A
└── PC A

Thread B
├── JVM Stack B
└── PC B

Thread C
├── JVM Stack C
└── PC C
```

如果所有线程共享一个 PC：

```text
         一个 PC
        /      \
Thread A        Thread B

A：我执行到20了
B：我执行到80了
```

那一个值根本无法同时表示不同线程各自的执行位置。

所以：

**每个线程都有自己的程序计数器，它天然是线程私有的。**

---

### **和“线程切换”联系起来理解**

你可以把每个线程想象成一个人在看书。

```text
小明 → JavaGuide 第 30 页
小王 → 小林Coding 第 80 页
小李 → JVM 第 120 页
```

老师说：

小明先别看了，小王开始看。

小明需要放一个：

**书签**

等轮到小明继续时：

```text
找到自己的书签
↓
第30页
↓
继续执行
```

如果三个人共用一个书签，那肯定乱套。

所以：

**一个线程 = 一本正在阅读的书**  
**程序计数器 = 这个线程自己的书签**

### **那为什么 JVM 栈也是线程私有？**

其实逻辑是一样的。

每个线程不仅：

**执行位置不同**

而且：

**正在调用的方法也不同。**

所以：

```text
Thread A
│
├── PC
│   └── 我执行到哪里了
│
└── JVM Stack
    └── 我现在调用了哪些方法


Thread B
│
├── PC
│   └── 我执行到哪里了
│
└── JVM Stack
    └── 我现在调用了哪些方法
```

因此你可以把 JVM 的线程私有区域理解成：

```text
每个线程自己的“执行现场”

├── 程序计数器
│   └── 执行到哪了
│
├── JVM虚拟机栈
│   └── Java方法怎么执行
│
└── 本地方法栈
    └── native方法怎么执行
```

这就解释了为什么我们之前背：

**两栈一计数器，线程私有。**

### Q：程序计数器有什么作用？为什么线程私有？

程序计数器是一块很小的线程私有内存区域，可以看作当前线程所执行字节码的行号指示器，用于记录线程当前执行的位置。字节码解释器执行时会根据它选取下一条需要执行的字节码指令。

因为 Java 支持多线程，线程之间会发生切换，每个线程执行到的位置都可能不同。为了在线程重新获得执行机会后能够恢复到正确的执行位置，每个线程都需要维护自己的程序计数器，所以它是线程私有的。



**PC 记录“线程执行到哪了”；每个线程执行位置不同，所以 PC 必须线程私有。**
