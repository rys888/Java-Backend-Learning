# 八股复习

日常只打开 [[今日八股复习]]，每篇前的复选框与原子笔记右上角的“标记今日复习”双向同步。

- 勾选或取消清单上的 `- [ ]`，会同步当前这篇原子笔记的按钮状态和今日热力图；点击原笔记按钮，也会同步勾选。
- 额外复习计划外的笔记仍正常计入热力图，但不计入清单进度，不跳过后续安排。以后抽到这些题目时，从未勾选开始。
- 在“今日八股复习”页点右上角按钮，可整份勾选或取消；不会更改计划外笔记的打卡。
- 历史清单仍可在 `每日记录/` 勾选或取消，并与原笔记按钮同步。打开历史清单后进入原笔记，会优先同步该清单；取消不删除过去日期的热力图记录。
- 默认每次 20 篇，总量可在 `配置.json` 的 `daily_count` 中改为 15–25。
- 每个自然日照常生成 20 篇新题，昨天没完成也不阻塞。所有清单都保留在 `每日记录/`，不另建待补复习文档。轮末不足 20 篇时安排本轮剩余题。
- 同一轮每篇只安排一次；本轮题目全部安排后，次日继续下一轮，不受旧清单完成情况影响。已完成轮数按实际全部勾选的轮次累计，旧轮次未完成时仍可继续出题。当前题库 216 篇，每天 20 篇约 11 天安排一轮。
- 每次更新重新扫描题库，新题加入当前轮后续队列，在所属板块优先安排。同一天反复更新不会换题。
- 完成状态按“轮次＋批次＋题目 ID”独立记录，通用热力图记录不直接参与抽题或轮次计算。升级时保留此前已记录的计划完成进度。
- 移动/改名通过唯一内容或唯一同名匹配尽量保留进度；同时改名和大幅改写可能识别为新题。删除题目不再要求复习，历史轮次保留。

[[复习进度]] 查看板块进度和轮次；`每日记录/` 保存每次清单。已结束轮次冻结，不因后来新增题目倒扣轮次。

## 自动更新

本机登录后每分钟检查一次，更新打卡进度、同步新增笔记，并在满足条件时生成次日清单。Mac 关机或休眠期间不运行，恢复后继续；文件内容没变时不重写。完全在本地运行，不消耗模型调用。

手动更新：在 Finder 双击 `更新复习.command`，或在本目录运行：

```sh
python3 更新复习.py
```

安装/恢复本机定时更新：

```sh
python3 安装自动更新.py
```

停止定时更新（保留所有内容）：

```sh
python3 安装自动更新.py --uninstall
```

生成任务读取热力图插件数据和 `.复习勾选.json`，不写插件打卡记录。Obsidian 中的 Java Review Heatmap 插件负责双向同步；复选框和按钮一般立即同步，顶部完整统计由每分钟任务更新。插件或勾选数据不可读时停止更新并记录在 `自动更新错误.log`，保留已有进度。

`.复习勾选.json` 与 `复习状态.json` 都需要保留。不要手动删除勾选数据；它按批次隔离，确保额外打卡不会完成未来清单。

## 题库规则

扫描 `java/八股笔记` 内的 Markdown。排除总目录、空白页、带站内链接的同名目录页及明确标注跳过的占位页。配置中的 `include` 可显式保留有正文的目录同名笔记，`exclude` 可排除指定题目，路径均相对“八股笔记”。

反射、异常、注解、深浅拷贝已显式保留。MyBatis 两份笔记的主体内容重复，其中含 `#` 文件名的副本会与双链标题定位冲突，因此排除该副本，保留 `Mybatis里的.md`，不改动原笔记。`题库索引.json` 可查看全部纳入与排除记录。

`复习状态.json` 保存题目身份、每日安排和轮次，请保留。机器可读状态与题库索引不需要日常打开。
