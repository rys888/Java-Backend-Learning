M2 重点有4条链路

## 链路 1：管理员设置部门的预算

前端传入(BudgetDTO)：
```
Body: {"deptId":2, "period":"2026-09", "totalAmount":50000, "status":1}
```

首先是 JWT 认证等先跳过后续再来了解，因为这也是一个业务模块

通过管理员传入 BudgetDTO：

```
admin/BudgetController.save(BudgetDTO)  
```

service 调用 save 想要增添这个预算，但是可能已经设置了，就异常处理

![[截屏2026-09-30 21.07.48.png]]

如果没有设置就调用 mapper 层的 insert 来插入这个部门的预算，注意 AutoFill 的 AOP 写入操作时间

![[截屏2026-09-30 21.13.52.png|229]]

xml 的内容很常规，所以就不写了
